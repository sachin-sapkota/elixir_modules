# MyApp

A simple Elixir application for managing todos.

## Getting Started

To run the application, you'll need Elixir installed on your system.

1. Install dependencies:
   ```bash
   mix deps.get
   ```

2. Run the application:
   ```bash
   mix run
   ```

## Modules

- `Todo` - Main module for todo operations
- `Todo.Model` - Data model for todos
